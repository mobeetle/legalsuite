# context — capability

**Contract.** Ground the run in the house's own context before judging or
writing anything, then hold one wording for one situation: sweep what the host
offers, build the reuse vocabulary, and pick from it — every substantive choice
traces to a vocabulary row or names its deviation.

Severity-scale `vocabulary.md` is untouched; this file is about wording reuse.
Mechanical house style (breaks, `&`, filler words, list punctuation) is
`style.md`.

## Sweep the available context first

Before the Gate Plan, inventory which tools, skills or connectors in this host
can supply matter context: company-wide policies, tickets, chats and
discussions, previous documents on similar topics, playbooks, workflow
definitions, and similar guidance. Then collect what is relevant — the review or
draft must be grounded in it, not written from a blank page.

- Record what was consulted (source + date) and what was looked for but
  unavailable. Unavailable is not absent: say which you mean.
- A load-bearing gap in the collected context is a clarification gate
  (`frame.md`, `gate.md`); anything else becomes `[ASSUMED]` with its basis
  (`provenance.md`).
- Precedence is unchanged (`configure.md`): mandatory law → the user's
  instruction in this matter → matter decisions → playbook → profile → pack
  defaults. House context fills gaps; it never overrides a higher layer.

## Reuse vocabulary

From the swept context, build the matter's reuse vocabulary **before** any
finding, redline or draft: the terms, phrases, sentences and clauses this house
uses in this situation, ordered by source — the bound playbook's clause library,
then the client template, then firm precedents, then the matter's own prior
documents. One row per item: wording · source · reuse strength.

- Strength is `must` (playbook preferred or house standard — reuse verbatim) or
  `should` (precedent default — reuse unless a reason says otherwise).
- Defined terms, including every Capitalized term, are the obligatory floor, not
  the ceiling: the vocabulary goes beyond them. Same situation, same wording —
  parallel phrasings for one meaning are the ambiguity this prevents.
- When drafting, reviewing, editing or modifying any text, pick from the
  vocabulary. A deliberate departure names its reason in the cover note or the
  finding; an accepted new wording feeds back into the matter vocabulary and, for
  playbook positions, into `deviations.md` (`positions.md`).

On an architect run the vocabulary lives in `reuse-vocabulary.md` at the matter
root (`../matter-folder.md`); on fast-track it is the short list in the turn.

## Checks

- The sweep (consulted + unavailable) is recorded before the Gate Plan.
- No finding, redline or draft text ships before its vocabulary row exists or its
  absence is stated with a reason.
- Every substantive wording choice traces to a vocabulary row, a defined term, or
  a named deviation — never to a fresh paraphrase of settled wording.
